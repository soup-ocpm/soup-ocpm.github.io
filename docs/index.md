## What is SOUP?

SOUP is a modular application for working with datasets and graph-oriented functionality. Its package architecture allows different capabilities to be developed and maintained independently of the core application.

The SOUP project includes integration with **Neo4j** and **Memgraph**. Available functionality and compatibility can vary by package and by the version of SOUP installed.

> **Documentation status**
> This is a **starter documentation site**, based on the current project context. Commands, supported package features, deployment settings, and compatibility should be checked against your actual SOUP repository before publication as authoritative documentation.
