# Getting started

This section introduces SOUP and the main workflow without assuming a particular installation method.

## Typical workflow

1. Start a SOUP instance using the instructions for your deployment.
2. Open the application in your browser.
3. Import or select a dataset.
4. Open a compatible package to work with the selected dataset.
5. Switch dataset or graph backend only when supported by your installed version and package.

## Vocabulary

- **Instance:** a running SOUP deployment with its own services and configuration.
- **Dataset:** data loaded into or managed by an instance.
- **Workspace:** the working context associated with a selected dataset.
- **Package:** a module providing functionality through the SOUP application.

For a conceptual overview, see [Architecture](../concepts/architecture.md).
